# Selective IgM deficiency

![Image](https://cwoer.ccbcmd.edu/science/microbiology/lecture/unit6/humoral/abystructure/images/u3fig9b.jpg)

![Image](https://icons.cdn.biorender.com/w550xh620/5b43b92f44457700149c1da4/5b43b8ec44457700149c1d99.png)

Selective IgM deficiency is an antibody deficiency where:

* IgM (immunoglobulin M) is low or absent
* IgG (immunoglobulin G) is normal
* IgA (immunoglobulin A) is normal

So it is "selective" because mainly one antibody class is missing: IgM.

---

### Core idea

IgM is the first antibody your body makes when it sees a new infection.

So if IgM is low, the immune system has a weaker early response, especially against:

* bacteria
* viruses
* fungi

This can cause recurrent infections, especially:

* sinusitis
* otitis media (middle ear infection)
* bronchitis
* pneumonia

---

### Why the findings happen

IgM normally acts like the immune system's early "alarm antibody."

It is a pentamer (5 antibody units joined together), so it has many antigen-binding sites.

That makes it good at:

* agglutination (clumping microbes together)
* complement activation (turning on proteins that help kill microbes)
* early infection control before class switching

Class switching means a B cell changes from making IgM to making another antibody class, like IgG, IgA, or IgE (immunoglobulin E).

So in selective IgM deficiency:

* early antibody defense is weak
* complement activation can be less effective
* recurrent respiratory infections can happen

---

### Associations

Selective IgM deficiency can be associated with:

* allergies, like asthma or allergic rhinitis (hay fever)
* autoimmune disease, like systemic lupus erythematosus (SLE), rheumatoid arthritis, or autoimmune thrombocytopenia
* poor response to polysaccharide vaccines, like Pneumovax-23

Polysaccharide means sugar-based capsule material on certain bacteria.

---

## One-line intuition

Selective IgM deficiency = normal IgG/IgA, but low IgM, so the immune system struggles with the first wave of antibody defense.

---

## HY pearl

IgM is the best antibody for activating complement because its pentamer shape lets it bind C1q efficiently.
