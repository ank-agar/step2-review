# Partial seizure

![Image](https://www.youngepilepsy.org.uk/sites/default/files/styles/media_block_inline_small/public/2025-07/brain-diagram-focal-seizures.png.webp?itok=6ME_udy4)

![Image](https://www.ncbi.nlm.nih.gov/books/NBK580614/bin/chapter2_f1.jpg)

![Image](https://upload.wikimedia.org/wikipedia/commons/1/10/Epilepsy-_right_hippocampal_seizure_onset.png)

A partial seizure is the older name for a **focal seizure**.

Meaning:

* the seizure starts in one specific part of one cerebral hemisphere
* symptoms depend on what that brain area normally does

So partial = only part of the brain is involved at the start.

---

### Core idea

A seizure is abnormal, excessive electrical firing in the brain.

In a partial/focal seizure, that firing starts locally:

* motor cortex involvement -> jerking or stiffening of one body part
* sensory cortex involvement -> tingling, numbness, odd sensations
* occipital lobe involvement -> visual symptoms, like flashing lights
* temporal lobe involvement -> deja vu, fear, odd smells, lip smacking, altered awareness

Occipital lobe = vision area.  
Temporal lobe = memory/emotion/smell/hearing area.

---

### Types

Old terms:

* **simple partial seizure** = awareness is preserved
* **complex partial seizure** = awareness is impaired

Newer terms:

* **focal aware seizure** = awake/aware during it
* **focal impaired awareness seizure** = awareness is reduced

So the key difference is:

> Can the patient stay aware and respond normally during the seizure?

---

### Why symptoms can look so different

Because the seizure "borrows" the function of the cortex it starts in.

Examples:

* motor cortex fires abnormally -> abnormal movement
* visual cortex fires abnormally -> abnormal vision
* temporal lobe fires abnormally -> weird memory/emotion symptoms
* autonomic areas fire abnormally -> sweating, nausea, flushing

Autonomic means involuntary body functions like heart rate, sweating, and digestion.

---

### Important spread pattern

A partial seizure can stay focal, or it can spread to both sides of the brain.

If it spreads widely, it can become a:

* **focal to bilateral tonic-clonic seizure**

Tonic-clonic means stiffening followed by rhythmic jerking.

This used to be called secondary generalization.

---

## One-line intuition

A partial seizure is a seizure that starts in one brain spot, so the symptoms tell you what that spot normally controls.

---

## Pearl

New focal seizure in an adult is concerning for a structural brain lesion, like tumor, stroke scar, abscess, or arteriovenous malformation (AVM, abnormal artery-vein connection), so brain imaging is important.
