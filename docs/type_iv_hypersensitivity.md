## Type IV hypersensitivity

![Image](https://microbenotes.com/wp-content/uploads/2018/06/Type-IV-Cell-Mediated-Hypersensitivity-Mechanism-and-Examples.jpg)

![Image](https://webpath.med.utah.edu/jpeg2/IMM039.gif)

![Image](https://medlineplus.gov/ency/images/ency/fullsize/2387.jpg)

Type IV hypersensitivity is a **delayed, T-cell-mediated immune reaction**.

Key idea:

* **No antibodies**
* **No immunoglobulin E (IgE)**
* **No mast-cell degranulation**
* mostly **T cells + macrophages**

It is called **delayed-type hypersensitivity (DTH)** because it usually takes **24-72 hours** to show up.

---

### Why it is delayed

Type I hypersensitivity is fast because pre-made antibodies and mast cells are ready to fire.

Type IV is slower because the body has to:

* recognize the antigen
* activate memory T cells
* release cytokines
* recruit macrophages
* create local inflammation

That cell recruitment takes time, so symptoms appear later.

---

### Main mechanism

Antigen-presenting cells (APCs) show antigen to **CD4+ T cells** (cluster of differentiation 4 positive helper T cells).

The CD4+ T cells, especially **T helper 1 (Th1) cells**, release cytokines like:

* **interferon-gamma (IFN-gamma)**, which activates macrophages
* **interleukin-2 (IL-2)**, which helps T cells proliferate

Then activated macrophages cause tissue inflammation and damage.

So the simple chain is:

> antigen exposure -> T cells remember it -> re-exposure -> T cells call macrophages -> delayed inflammation

---

### Classic examples

Type IV hypersensitivity includes:

* **contact dermatitis** from poison ivy or nickel
* **tuberculin skin test** / purified protein derivative test (PPD test)
* **granuloma formation** in tuberculosis
* **type 1 diabetes mellitus**, where cytotoxic T cells attack pancreatic beta cells
* **multiple sclerosis**, where immune cells damage myelin
* **transplant rejection**

---

### Intuition

Think:

> Type IV = T cells take time.

The immune system is not dumping histamine right away. It is building a local cellular army, especially macrophages, and that is why the reaction is delayed.

---

### Why granulomas happen

If macrophages cannot kill something, like **Mycobacterium tuberculosis**, T cells keep activating them.

The body tries to wall off the persistent antigen by forming a **granuloma** (organized collection of activated macrophages and immune cells).

That is still Type IV hypersensitivity because the damage is driven by T-cell cytokines and macrophage activation.

---

## One-line intuition

Type IV hypersensitivity is a delayed immune attack where **T cells recruit macrophages**, causing inflammation hours to days later.

---

## Pearl

Type IV hypersensitivity is the **only hypersensitivity type that is not antibody-mediated**; Step 1 loves the clue **"delayed 48-72 hours"** for poison ivy, nickel allergy, or the PPD skin test.
