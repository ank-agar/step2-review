# Tetanus

![Image](https://upload.wikimedia.org/wikipedia/commons/thumb/f/fd/Mechanism_of_action_of_tetanospasmin.gif/500px-Mechanism_of_action_of_tetanospasmin.gif)

![Image](https://wwwn.cdc.gov/phil/PHIL_Images/20041014/b9e12f3f8918406b960fa8f84cc4c533/6372_lores.jpg)

Tetanus is a disease caused by **Clostridium tetani**, an anaerobic (grows without oxygen), spore-forming, gram-positive rod.

The classic association is:

* puncture wound
* contaminated soil
* muscle rigidity/spasms
* “lockjaw”

---

### Core idea

Clostridium tetani makes **tetanospasmin**, a toxin that blocks inhibitory neurons.

Inhibitory neurons normally release:

* GABA (gamma-aminobutyric acid)
* glycine

These calm down motor neurons.

So if tetanus blocks GABA/glycine release:

* motor neurons lose inhibition
* muscles contract too much
* you get spastic paralysis

---

### Why the symptoms happen

Tetanospasmin enters nerves at the wound and travels backward up the nerve by **retrograde axonal transport** (movement from nerve ending back toward the spinal cord).

Then it blocks **SNARE proteins** (proteins that help neurotransmitter vesicles fuse and release their contents).

No vesicle fusion means:

* no GABA/glycine release
* no “brake” on motor neurons
* sustained muscle contraction

That causes:

* trismus = lockjaw
* risus sardonicus = rigid “smile”
* opisthotonos = severe back arching from spasms

---

### Botulinum vs tetanus

Both toxins affect SNARE proteins.

But:

* botulinum toxin blocks acetylcholine release at the neuromuscular junction, causing flaccid paralysis
* tetanus toxin blocks GABA/glycine release in the spinal cord, causing spastic paralysis

One-line memory:

**Botulinum = floppy baby. Tetanus = tight muscles.**

---

## One-line intuition

Tetanus removes the spinal cord’s inhibitory brake, so motor neurons fire nonstop and muscles stay painfully contracted.

---

## Pearl 🔥

Tetanus infection does **not** give reliable immunity because very tiny amounts of toxin can cause disease, so patients still need tetanus toxoid vaccination after infection.
