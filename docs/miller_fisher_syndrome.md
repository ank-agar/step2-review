## Miller Fisher syndrome

![Image](https://www.frontiersin.org/files/Articles/1763283/xml-images/fneur-17-1763283-g002.webp)

![Image](https://www.frontiersin.org/files/Articles/1763283/xml-images/fneur-17-1763283-g003.webp)

### Core idea

Miller Fisher syndrome is a rare variant of **GBS (Guillain-Barre syndrome)**.

Classic triad:

* ophthalmoplegia (eye movement paralysis)
* ataxia (poor coordination)
* areflexia (absent reflexes)

Think:

> eyes cannot move + walking is wobbly + reflexes are gone.

---

### Mechanism

Usually, it happens after an infection, especially:

* Campylobacter jejuni
* Haemophilus influenzae

The infection triggers antibodies that accidentally attack nerve gangliosides.

The classic antibody is:

* anti-GQ1b antibody

GQ1b is a ganglioside (nerve membrane glycolipid) highly found around:

* cranial nerves III, IV, VI, which move the eyes
* muscle spindle afferents, which help proprioception (sense of body position)

So anti-GQ1b antibodies hit these areas.

That explains:

* cranial nerve III/IV/VI involvement → ophthalmoplegia
* proprioception disruption → ataxia
* peripheral nerve/reflex arc involvement → areflexia

---

### Why it looks like this

**Ophthalmoplegia** happens because the eye movement nerves are especially vulnerable.

**Ataxia** happens because the brain is not getting clean position-sense information from the body, so movement becomes uncoordinated.

**Areflexia** happens because reflexes need an intact peripheral nerve loop. If the sensory/motor reflex arc is impaired, the reflex disappears.

---

### Important distinction

Miller Fisher syndrome is usually more cranial nerve/coordination focused than classic GBS (Guillain-Barre syndrome).

Classic GBS:

* ascending weakness
* areflexia

Miller Fisher syndrome:

* ophthalmoplegia
* ataxia
* areflexia

Mental status is usually normal. If there is altered consciousness, think about Bickerstaff brainstem encephalitis, which is related to the same anti-GQ1b antibody spectrum.

---

### Diagnosis clues

Helpful findings:

* anti-GQ1b antibody
* CSF (cerebrospinal fluid) albuminocytologic dissociation

Albuminocytologic dissociation means:

* high CSF protein
* normal CSF white blood cell count

Same idea as GBS (Guillain-Barre syndrome): inflamed nerves leak protein, but there is not a big WBC (white blood cell) response like meningitis.

---

### Treatment idea

Treatment is similar to GBS (Guillain-Barre syndrome):

* IVIG (intravenous immunoglobulin)
* plasmapheresis (plasma exchange)
* monitor breathing and swallowing if severe

Many patients recover well, but it is still taken seriously because it is in the GBS family.

---

## One-line intuition

Miller Fisher syndrome = post-infectious anti-GQ1b antibodies attack eye movement nerves and proprioceptive/reflex pathways → ophthalmoplegia + ataxia + areflexia.

---

## Pearl 🔥

Anti-GQ1b antibody is the HY (high-yield) association for Miller Fisher syndrome.
