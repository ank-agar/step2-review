# First-degree AV block

![Image](https://upload.wikimedia.org/wikipedia/commons/b/ba/FirstAVBlock.jpg)

![Image](https://upload.wikimedia.org/wikipedia/commons/a/ae/ConductionsystemoftheheartwithouttheHeart-en.svg)

### Core idea

First-degree AV block means the electrical signal from the atria to the ventricles is delayed, but every signal still gets through.

AV block = atrioventricular block.

* atrio = atria, the upper heart chambers
* ventricular = ventricles, the lower heart chambers
* AV node = atrioventricular node, the electrical gate between atria and ventricles

So first-degree AV block is really:

> slow conduction through the AV node, not a true complete block.

---

### What the ECG shows

ECG (electrocardiogram) classically shows:

* PR interval greater than 200 ms (milliseconds)
* every P wave followed by a QRS complex
* no dropped beats

PR interval = time from atrial depolarization to ventricular depolarization.

In simpler words:

* P wave = atria electrically activate
* QRS complex = ventricles electrically activate
* long PR interval = the signal is taking too long to travel from atria to ventricles

---

### Why it happens

Normally, the SA node (sinoatrial node, the heart's natural pacemaker) fires first.

Signal path:

* SA node
* atria
* AV node
* His-Purkinje system
* ventricles

In first-degree AV block, the AV node pauses longer than normal before passing the signal forward.

That delay stretches the PR interval.

But because the signal still reaches the ventricles every time, there are no missing QRS complexes.

---

### Common causes

Anything that slows AV node conduction can cause it:

* increased vagal tone
* beta blockers
* calcium channel blockers
* digoxin
* inferior myocardial infarction
* Lyme disease

Vagal tone = parasympathetic nervous system input that slows the heart.

Myocardial infarction = heart attack.

---

## One-line intuition

First-degree AV block is a long AV-node delay: the atrial signal is slow to reach the ventricles, but it still gets there every beat.

---

## Pearl 🔥

Step 1 pattern: first-degree AV block = PR interval greater than 200 ms + 1 P wave before every QRS + no dropped beats.
