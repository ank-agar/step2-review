# Second-degree AV block

![Image](https://upload.wikimedia.org/wikipedia/commons/thumb/0/03/2nd_Degree_AV_Block_%28Mobitz_II%29.svg/960px-2nd_Degree_AV_Block_%28Mobitz_II%29.svg.png)

### Core idea

Second-degree AV block (atrioventricular block) means:

* some atrial impulses get through to the ventricles
* some atrial impulses do not

So on ECG (electrocardiogram), you see:

* P waves (atrial depolarization)
* but some P waves are not followed by QRS complexes (ventricular depolarization)

That missed QRS is the key.

---

### Two main types

**Mobitz I / Wenckebach**

PR interval (time from atrial depolarization to ventricular depolarization) gets longer and longer, then a beat drops.

Think:

> longer, longer, longer, drop.

Usually problem is in the AV node (atrioventricular node), so it is often less dangerous.

**Mobitz II**

PR interval stays the same, then suddenly a beat drops.

Think:

> same, same, same, drop.

Usually problem is below the AV node in the His-Purkinje system (ventricular conduction fibers), so it is more dangerous.

---

### Why the findings happen

The SA node (sinoatrial node) still fires normally, so P waves keep appearing.

But the AV node/His-Purkinje pathway sometimes fails to pass the signal down to the ventricles.

If the signal does not reach the ventricles:

* no ventricular depolarization
* no QRS complex
* skipped heartbeat

---

## One-line intuition

Second-degree AV block = the atria keep sending messages, but the ventricles only receive some of them.

---

## Pearl 🔥

Mobitz II is the scary one because it can progress to complete heart block (third-degree AV block), so it often needs a pacemaker.
