# Anisocoria

![Image](https://www.ncbi.nlm.nih.gov/sites/books/NBK553169/bin/Imagen8.jpg)

![Image](https://upload.wikimedia.org/wikipedia/commons/thumb/a/a8/Anisocoria0.jpg/960px-Anisocoria0.jpg)

### Core idea

Anisocoria = unequal pupil sizes.

Usually the question is:

* is the big pupil abnormal?
* or is the small pupil abnormal?

---

### How to tell

Compare the pupils in bright light vs dark.

If anisocoria is worse in **bright light**:

* the **large pupil** is abnormal
* why? it cannot constrict
* think parasympathetic problem

Parasympathetic nerves normally constrict the pupil using the sphincter pupillae muscle.

Causes include:

* CN III (cranial nerve 3, oculomotor nerve) palsy
* Adie tonic pupil
* anticholinergic drugs
* iris trauma

---

If anisocoria is worse in **darkness**:

* the **small pupil** is abnormal
* why? it cannot dilate
* think sympathetic problem

Sympathetic nerves normally dilate the pupil using the dilator pupillae muscle.

Classic cause:

* Horner syndrome

Horner syndrome =:

* ptosis (droopy eyelid)
* miosis (small pupil)
* anhidrosis (decreased sweating)

---

## One-line intuition

Bright light tests constriction, so the pupil that stays too big is broken. Darkness tests dilation, so the pupil that stays too small is broken.

---

## Pearl 🔥

Physiologic anisocoria is common and benign, usually small and stable, but **new anisocoria with headache, ptosis, eye movement problems, or neurologic symptoms is concerning** for things like CN III compression or Horner syndrome from carotid dissection/Pancoast tumor.
