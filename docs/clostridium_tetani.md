### Core idea

Clostridium tetani is a **gram-positive, spore-forming, obligate anaerobic rod** that causes **tetanus**.

Break that down:

* **gram-positive** = stains purple because of a thick cell wall
* **spore-forming** = can survive harsh environments as dormant spores
* **obligate anaerobe** = grows best where there is little/no oxygen
* **rod** = bacillus-shaped bacterium

Classic morphology:

* **terminal spores**
* “drumstick” or “tennis racket” appearance

---

### How it causes disease

The spores enter through a dirty/deep wound, especially a puncture wound.

Why deep wounds matter:

* deep tissue has low oxygen
* low oxygen lets the anaerobic bacteria germinate
* then it releases **tetanospasmin** (tetanus neurotoxin)

Tetanospasmin travels backward up nerves to the **CNS** (central nervous system).

There, it blocks release of:

* **GABA** (gamma-aminobutyric acid)
* glycine

These are inhibitory neurotransmitters, meaning they normally calm motor neurons down.

So if you block inhibition:

> no brake on motor neurons → constant muscle contraction → spastic paralysis

---

### Classic findings

Tetanus causes:

* trismus = lockjaw
* risus sardonicus = forced grimace
* opisthotonos = severe back arching
* muscle spasms
* autonomic instability = abnormal blood pressure/heart rate control

The key is **spastic paralysis**, not flaccid paralysis.

---

## One-line intuition

Clostridium tetani makes a toxin that removes the “brakes” from motor neurons, so muscles stay painfully contracted.

---

## Pearl 🔥

Tetanus prevention uses **toxoid vaccine**: an inactivated toxin that teaches the immune system to neutralize tetanospasmin.

HY contrast:

* **C. tetani** → blocks GABA/glycine release → spastic paralysis
* **C. botulinum** → blocks acetylcholine release at neuromuscular junction → flaccid paralysis
